## Deskripsi Project
<p align="justify">
Tugas ini merupakan implementasi komponen WebView pada aplikasi mobile berbasis React Native dengan menggunakan arsitektur Fabric atau New Architecture. Pengembangan aplikasi dilakukan dengan memanfaatkan paket react-native-webview untuk menampilkan halaman website eksternal secara langsung di dalam aplikasi. Melalui tugas ini, mahasiswa diharapkan memahami penerapan komponen WebView pada React Native modern serta mengenal arsitektur Fabric yang menawarkan proses rendering lebih cepat, responsif, dan sinkron. Implementasi ini juga menjadi pengembangan dari tugas sebelumnya yang menggunakan MIT App Inventor, dengan pendekatan pengembangan aplikasi berbasis React Native.
</p>
